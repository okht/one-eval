The tested version completed real repeated LLM judging with two requested models and a local stateful HTTP integration using native Codex conversation resume. All final acceptance checks passed. Two stateful execution attempts failed with explicit model-capacity errors and succeeded after one explicit retry each; both original failures remain available.

## Real judging

Both `gpt-5.6-sol` and `gpt-5.6-luna` were present in local supported-model metadata and passed a real readiness call through native `codex-cli 0.144.6`. Every judge call started a fresh ephemeral CLI thread with tools and memory disabled. The requested model identifier, raw events, usage, exact input and timestamps are preserved. The CLI event stream does not independently expose a resolved server-side model identifier.

The strict-rule fixtures cover correct answers, incorrect answers, empty output, Chinese text and visually similar emoji, candidate prompt injection, missing grading rules, exact numeric spelling and two previously saved GSM8K answers. The original benchmark target was never called again. Each model matched all 24 expected outcomes. Of the 48 judgments, 44 returned a score and four correctly returned `insufficient_evidence` for missing rules. Pairwise status/score agreement was 24/24. There were 48 unique judge threads, with no repeated grading slot and no calibration labels or expected score bands included in judge inputs.

The separate semantic rubric grants 0.5 for correctly explaining current cancellation eligibility and 0.5 for communicating all required refund details. The three saved responses deliberately cover a full paraphrase (expected 1), a clear contradiction (expected 0), and a response satisfying only the cancellation requirement (expected 0.5). Both models assigned all three expected values on both repetitions. Expected values were fixed in files before invocation. These fixtures were authored by the evaluation agent; they are not human annotations or an expert-quality benchmark. The 12 semantic calls also used 12 unique fresh threads and withheld expected labels.

The strict and semantic graders have separate configuration hashes and calibration run directories. Existing strict-rule answers, prompts and records were not altered when semantic calibration was added.

## Native stateful service

A disposable loopback HTTP service creates and owns each conversation session. Its first turn opens a new native Codex thread. Subsequent HTTP requests contain only the newest user message and invoke `codex exec resume <thread-id>`. No previous assistant or user transcript is replayed by the target adapter. The final 12 trials used 12 unique native threads and 22 successful model turns, including 10 native resume calls. Every resumed call returned its expected thread ID.

Recall, overwrite, clearing and blank-new-session checks all passed the exact complete-dialogue grader. Initial isolation verification checked zero turns, no assigned thread and an empty owned working directory. Cleanup deleted each service session, verified a 404 lookup, and removed its working directory. The audit recorded both service shutdowns with zero remaining active sessions. Codex's persisted native session history remains available for audit; cleanup does not claim to erase the global Codex history.

Both first-attempt failures affected the overwrite scenario, one in each repetition. The raw CLI error was `Selected model is at capacity. Please try a different model.` The first report correctly had 10 completed trials, two execution failures and `overall: null`. After the initial run finished, a separate operator retry command retried only those failed trials, with fresh sessions, once each. All completed answers stayed unchanged. The final report is complete with score 1. The initial failure artifacts, first report, raw errors and later attempts are retained.

## Call accounting and evidence

The full acceptance consumed **88 recorded CLI invocations**: two readiness calls, 48 strict-rule judge calls, 12 semantic judge calls and 26 stateful calls across all attempts. Eighty-six completed and two failed. The stateful calls include 22 successful turns in final attempts, two successful turns in the superseded incomplete attempt, and two failed calls. No valid low score was retried.
